# Конфиг поиска — Маркетолог

> ЧТО искать на HH каждое утро. Дил-брейкеры и условия — в `../facts/предпочтения.md`
> (их проверяет аналитик на «воротах»). Технику запроса выполняет `../scripts/hh-fresh.sh`.

**Статус:** ✅ настроено (маркетинг / полная удалёнка / за сутки).

## Параметры HH API (дефолты скрипта)
| Параметр | Значение | env-переменная |
|---|---|---|
| Текст запроса | `NAME:(маркетолог OR email-маркетолог OR CRM-маркетолог OR performance-маркетолог OR digital-маркетолог OR интернет-маркетолог)` | `HH_TEXT` |
| Регион | 113 (вся Россия) | `HH_AREA` |
| График | `remote` (полная удалёнка) | `HH_SCHEDULE` |
| Период | 1 (за последние сутки) | `HH_PERIOD` |
| Вакансий на страницу | 100 | `HH_PER_PAGE` |
| Сколько тянуть полный текст | 15 | `HH_MAX_DETAIL` |

Пример разового запуска с другими параметрами:
```bash
HH_PERIOD=3 HH_TEXT='NAME:(email-маркетолог)' bash scripts/hh-fresh.sh
```

## Фильтры «после запроса» (делает пайплайн, не API)
- **Дедуп:** вакансии с id из `../data/seen-vacancies.md` не показываются повторно.
- **Ворота (аналитик):** полная удалёнка обязательна; дил-брейкер-индустрии
  (алкоголь, табак, гэмблинг, ставки, оружие, товары двойного назначения) — отсев.
- **Зарплата:** минимум 110 000 ₽ **на руки**. По API жёстко не режем (много вакансий
  без указанной вилки) — оценку делает аналитик; где вилка ниже минимума, помечаем.

## Как поменять, что искать
Отредактируй строку `HH_TEXT`/`HH_*` выше и в `../scripts/hh-fresh.sh` (блок дефолтов),
либо передавай env-переменные при запуске. Роль/ключевые слова — здесь единый источник.
