# Дайджесты утреннего агента

Сюда утренний агент складывает ежедневные подборки свежих вакансий с HH:
файл `YYYY-MM-DD.md` за каждый запуск. Внутри по каждой новой вакансии —
результат аналитика (ворота → вердикт) и, если вакансия прошла ворота,
черновик сопроводительного из `facts/`.

Дайджест — это черновик для тебя: агент **не откликается сам**, только находит,
анализирует и готовит письма. Решение и отклик — за тобой.
