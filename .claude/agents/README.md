# Отдел ИИ-агентов — поиск работы (Маркетолог)

Здесь живут агенты-специалисты. Каждый — «сотрудник» со своей ролью, который
работает с фактами кандидата (`facts/`), бренд-гайдом (`brand/`) и воронкой
вакансий (`companies/`). Общий принцип отдела — из **WORKFLOW.md**: факты только
в `facts/`, материалы собираются из фактов под конкретную вакансию.

## Состав отдела

| Агент | Роль | Чем занимается |
|---|---|---|
| `analitik-vakansiy` | Аналитик вакансий | Разбирает вакансию: требования, красные флаги, матч с профилем, что подчеркнуть, вердикт |
| `sostavitel-materialov` | Составитель материалов | Собирает резюме/сопроводительные/отклики под вакансию строго из `facts/` |
| `redaktor-chelovechnost` | Редактор-человечность | Финальная вычитка любого текста через скилл `chelovechnost` + бренд-гайд |
| `assistent-sobesedovaniy` | Ассистент собеседований | Готовит ответы на вопросы HR, тренирует к встречам, ведёт `answers-registry.md` |
| `koordinator-trekera` | Координатор трекера | Держит `companies-tracker.md` и карточки в актуальном виде, следит за дедлайнами |

## Как это связано с командами и скиллами

- Команды `/трекер` и `/кейсы-экстракт` (`.claude/commands/`) — конкретные операции,
  которые агенты используют или предлагают запустить.
- Скилл `chelovechnost` — включается на финальной вычитке текстов.
- Агенты — самостоятельные роли: им даёшь задачу, они доводят её до результата,
  опираясь на `facts/`, и передают работу дальше (например, составитель → редактор).

## Типовой маршрут работы

1. Пришла вакансия → **аналитик вакансий** оценивает, стоит ли откликаться.
2. Решили идти → **составитель материалов** собирает резюме/сопроводительное из `facts/`.
3. Текст готов → **редактор-человечность** вычищает звучание.
4. Позвали на собес → **ассистент собеседований** готовит к встрече.
5. Весь путь → **координатор трекера** держит воронку в порядке.
