# 04 — Маркетинговые навыки

Уровни: **эксперт** / **уверенно** / **базово**.

## Каналы привлечения
- **Performance / контекст:** Яндекс.Директ — эксперт; Google Ads — уверенно; VK Ads — эксперт; Telegram Ads — уверенно; Meta (Facebook/Instagram) Ads — уверенно; MyTarget — уверенно
- **Гео-маркетинг:** 2ГИС, Яндекс.Карты — уверенно
- **Посевы, таргетинг** в VK и Telegram — уверенно
- **SEO:** управление подрядчиком, приоритизация, техаудит сайта — уверенно (руководящий уровень, не «ручной» специалист)
- **SMM / контент:** организация контент-производства (Reels/Shorts/Stories) — уверенно
- **PR:** экспертные публикации в СМИ — уверенно
- **Инфлюенс / UGC:** привлечение блогеров, масштабирование — уверенно
- **Email / CRM-маркетинг, автоворонки, мессенджер-рассылки** — эксперт (retention, реактивация)

## Аналитика и данные
- **Веб-аналитика:** Яндекс.Метрика, Google Analytics — уверенно
- **Сквозная аналитика:** Calltouch + Битрикс24, UTM-разметка с нуля — эксперт
- **Продвинутая аналитика:** RFM-, ABC-, когортный анализ; unit-экономика — эксперт
- **Данные:** SQL-выгрузки, API CRM, BigQuery, выгрузки из 1С — уверенно
- **Метрики:** ROMI, ROI, CAC, LTV, CPL, CPA, DRR, средний чек, конверсия
- **Roistat** — уверенно
- **Google Sheets / Excel:** уровень 5/5 — формулы, сводные, аналитика _(квиз, вопрос 9)_

## Стратегия и бренд
- Маркетинговая стратегия «с нуля», позиционирование, анализ конкурентов и ЦА — эксперт
- CJM / путь клиента от первого касания до повторных покупок
- Офферы, смыслы, A/B-тесты, связки офферов
- CustDev / исследования аудитории
- GTM / запуск высокочековых продуктов (наставничество, флагманы)

## AI-инструменты
- Внедрение ИИ и нейросетей для контента, аналитики, презентаций
- Автоматизация рутины через API + скрипты + ИИ (пример: рутинная задача 60 → 20 мин)

## Инструменты
- **CRM:** Битрикс24 — уверенно; amoCRM / др. — базово
- **LMS:** GetCourse — уверенно
- **Проджект:** Trello / ClickUp / YouGile / Asana / Notion — уверенно
- **Дизайн:** Figma, Canva, Miro — на уровне просмотра/комментариев и сборки лендингов
- **Таблицы:** Google Sheets / Excel — эксперт
