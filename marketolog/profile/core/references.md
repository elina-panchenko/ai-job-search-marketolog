# 08 — Рекомендации (опционально)

Рекомендаций пока что нет. Предстоит сформировать, пока что очень страшно.

Для каждой рекомендации полезно указать:
- Имя
- Должность
- Компания
- Контакты
- Отношение к кандидату (руководитель / коллега / клиент)

> Заполнить при желании — рекомендации усиливают отклик на Head-роли.
