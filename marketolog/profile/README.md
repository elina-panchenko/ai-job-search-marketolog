# Профиль кандидата — Панченко Элина

Структурированный профиль для AI Job Search по направлению **Маркетолог**. Устроен по принципу: общая фактическая база (`core/`) + трек под конкретную роль (`tracks/2-marketolog/`).

👉 **Способ работы описан в [`WORKFLOW.md`](WORKFLOW.md)** — прочитать первым.

## Структура

```
profile/
├── WORKFLOW.md                     способ работы
├── core/                           общая фактическая база (факты о кандидате)
│   ├── identity.md                 контакты, локация, языки
│   ├── education.md                образование, курсы, сертификаты
│   ├── experience-master.md        полный фактический опыт (все цифры)
│   ├── skills-master.md            полный набор навыков
│   ├── project-management.md       PM-навыки (факты из квиза)
│   ├── preferences-constraints.md  формат, доход, дил-брейкеры, доступность
│   ├── messaging-bank.md           готовые формулировки (voice) для писем и ответов
│   └── references.md               рекомендации
└── tracks/
    └── 2-marketolog/               🟢 Маркетолог — своё резюме, кейсы, позиционирование, конфиг поиска
```
