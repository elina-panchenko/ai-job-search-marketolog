# ai-job-search — Маркетолог

Репозиторий поиска работы по направлению **Маркетолог** (специалист / senior / performance / стратег).

Выделен из общего мульти-трек репозитория в отдельный репо под один трек. Общая фактическая база кандидата (`profile/core/`) перенесена целиком — из неё берутся все факты, трек их переупаковывает под роль.

## Структура

```
.
├── prompts-profile          промпты для сбора профиля (маркетинг/PM)
├── companies-tracker.md     трекер вакансий по треку Маркетолог
├── companies/               файлы по каждой вакансии (+ _шаблон.md)
└── profile/
    ├── README.md            о профиле
    ├── WORKFLOW.md          способ работы
    ├── core/                общая фактическая база (факты о кандидате)
    └── tracks/
        └── 2-marketolog/    трек Маркетолог (резюме, кейсы, позиционирование, конфиг поиска)
```

## С чего начать
1. `profile/WORKFLOW.md` — способ работы.
2. `profile/core/` — фактическая база (заполнена).
3. `profile/tracks/2-marketolog/` — наполнение трека под роль.
