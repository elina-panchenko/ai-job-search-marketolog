# Бренд — Элина · Маркетинг по полочкам

Материалы личного бренда: логотип и концепции.

## Текущий логотип

Файл: [`logo.svg`](./logo.svg) — Концепция «Полочки».

Три горизонтальные полки, на которых «разложены» фигуры (треугольник, круг, квадрат) —
прямое воплощение метафоры бренда «всё по полочкам»: система вместо хаоса.

**Цвета:**
| Элемент | HEX |
|---|---|
| Полки | `#241C24` |
| Треугольник | `#8C2E9A` |
| Круг | `#141414` |
| Квадрат | `#5F7E6F` |
| Фон | `#ECEAEB` |

> SVG — вектор: масштабируется без потерь, цвета и размеры легко править прямо в файле.
> Для прозрачного фона удали первый `<rect>` в `logo.svg`.

## Три концепции логотипа

1. **Полочки** — метафора порядка. Полки с разложенными фигурами. *(реализована в `logo.svg`)*
2. **Монограмма Э** — личная подпись-печать эксперта; буква «Э» читается как три полки.
3. **Траектория к результату** — линия из хаоса слева в чёткую восходящую точку-цель справа.

Полные описания концепций — в истории обсуждения бренда.
