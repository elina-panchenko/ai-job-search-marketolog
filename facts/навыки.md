# 04 — Маркетинговые навыки

Уровни: **эксперт** / **уверенно** / **базово**.

## Каналы привлечения
- **Performance / контекст:** Яндекс.Директ — уверенно; Google Ads — уверенно; VK Ads — эксперт; Telegram Ads — эксперт; Meta (Facebook/Instagram) Ads — эксперт; MyTarget — эксперт
- **Гео-маркетинг:** 2ГИС, Яндекс.Карты — эксперт
- **Посевы, таргетинг** в VK и Telegram — эксперт
- **SEO:** управление подрядчиком, приоритизация, техаудит сайта — базово, уверенно руководящий уровень, не «ручной» специалист
- **SMM / контент:** организация контент-производства (Reels/Shorts/Stories) — эксперт
- **PR:** экспертные публикации в СМИ — уверенно
- **Инфлюенс / UGC:** привлечение блогеров, масштабирование — эксперт
- **Email / CRM-маркетинг, автоворонки, мессенджер-рассылки** — эксперт (retention, реактивация)

## Аналитика и данные
- **Веб-аналитика:** Яндекс.Метрика, Google Analytics — эксперт
- **Сквозная аналитика:** Calltouch + Битрикс24, UTM-разметка с нуля — эксперт
- **Продвинутая аналитика:** RFM-, ABC-, когортный анализ; unit-экономика — эксперт
- **Данные:** SQL-выгрузки, API CRM, BigQuery, выгрузки из 1С — эксперт
- **Метрики:** ROMI, ROI, CAC, LTV, CPL, CPA, DRR, средний чек, конверсия — эксперт
- **Roistat** — эксперт
- **Google Sheets / Excel:** уровень 5/5 — формулы, сводные, аналитика — эксперт

## Стратегия и бренд
- Маркетинговая стратегия «с нуля», позиционирование, анализ конкурентов и ЦА — эксперт
- CJM / путь клиента от первого касания до повторных покупок — эксперт
- Офферы, смыслы, A/B-тесты, связки офферов — эксперт
- CustDev / исследования аудитории — эксперт
- GTM / запуск высокочековых продуктов (наставничество, флагманы) — уверенно

## AI-инструменты
- Внедрение ИИ и нейросетей для контента, аналитики, презентаций — эксперт
- Автоматизация рутины через API + скрипты + ИИ (пример: рутинная задача 60 → 20 мин) — эксперт

## Инструменты
- **CRM:** Битрикс24 — уверенно; amoCRM / др. — эксперт
- **LMS:** GetCourse — уверенно
- **Проджект:** Trello / ClickUp / YouGile / Asana / Notion — эксперт
- **Дизайн:** Figma, Canva, Miro — уверенно
- **Таблицы:** Google Sheets / Excel — эксперт
