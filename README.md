# ai-job-search — Маркетолог

Репозиторий поиска работы по направлению **Маркетолог** (специалист / senior / performance / стратег).

Устроен просто, в два смысловых слоя: **факты о кандидате** (`facts/`) → **материалы для работодателя** (`materials/`), собранные из фактов под конкретную вакансию. Плюс воронка вакансий.

## Структура

```
.
├── README.md                 обзор + с чего начать
├── WORKFLOW.md               правила работы (факты → материалы)
├── prompts-profile.md        промпты для сбора профиля (маркетинг)
│
├── facts/                    ФАКТЫ о кандидате (не меняются, единственный источник правды)
│   ├── общие-данные-контакты.md    контакты, локация, языки
│   ├── образование.md              образование, курсы, сертификаты
│   ├── опыт.md                     полный фактический опыт (все места, все цифры)
│   ├── навыки.md                   полный набор навыков
│   ├── навыки-руководства.md       навыки руководителя
│   ├── предпочтения.md             формат, доход, дил-брейкеры, доступность
│   ├── примеры-формулировок.md     готовые формулировки (voice) для писем и ответов
│   ├── рекомендательные-письма.md  рекомендации
│   └── cases.md                    пул кейсов и работ
│
├── materials/                что подаём работодателю (собрано из facts/ под роль)
│   ├── resume.md             резюме под роль
│   ├── positioning.md        позиционирующие формулировки
│   └── job-search-config.md  тайтлы и ключевые слова для поиска
│
├── brand/                    БРЕНД (тон, ценности, визуал)
│   └── бренд-гайд.md         тон бренда, миссия, ценности, ЦА, шрифты, цвета
│
├── companies-tracker.md      сводная таблица вакансий
├── companies/                по файлу на каждую вакансию (+ _шаблон.md)
└── answers-registry.md       полный реестр всех моих ответов на вопросы анкет/HR
```

## С чего начать
1. `WORKFLOW.md` — способ работы (факты → материалы).
2. `facts/` — фактическая база (заполнена).
3. `materials/` — наполнение материалов под роль.
4. `companies-tracker.md` — учёт вакансий и подготовка к собесам.

## Статус наполнения
- **Факты (`facts/`):** ✅ заполнены из резюме, кейсов и квиза.
- **Материалы (`materials/`):** ⬜ собираются — резюме, кейсы, позиционирование, конфиг поиска.
