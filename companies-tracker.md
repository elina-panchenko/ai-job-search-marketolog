# Трекер компаний — Маркетолог

Сводная таблица по вакансиям. Подробности по каждой вакансии — в отдельном файле в папке [`companies/`](companies/). Цель — **готовиться к собеседованиям**: перед звонком открываю файл компании и вижу полную картину.

## Как пользоваться

1. Новая вакансия → копирую [`companies/_шаблон.md`](companies/_шаблон.md) в новый файл (например `companies/acme-marketolog.md`), заполняю. Добавляю строку в сводную таблицу со ссылкой на этот файл.
2. После каждого контакта (письмо, звонок, сообщение) → дописываю в файл компании + обновляю `Статус` и `Следующий шаг` в таблице.
3. Перед собесом → читаю файл компании: обещания, условия, вопросы, красные флаги.
4. В файл компании складываю всё: ссылку на вакансию, версию резюме, переписку, мои ответы, тестовое, заметки.
5. Даты в формате `ГГГГ-ММ-ДД`. Ссылку на вакансию сохраняю сразу (вакансии удаляют).
